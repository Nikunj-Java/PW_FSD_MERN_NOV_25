1. Create a directory
--------------------------------
> mkdir demo   

2. move to directory
--------------------------------
> cd demo

3. get the current working directory
-------------------------------------
> pwd

4. Copy a file 
-------------------------------------
> cp source.txt dest.txt

5. moving a file
-------------------------------------
mv oldname.txt newname.txt

6. moving a file to a destionation
--------------------------------------
mv file.txt /path/to/destination

7. Multi Command Line Input
---------------------------------------
cat <<EOF > greeting.txt
Hello
How Are you
This is Multi-Line Input
EOF

8. Single Line Input
----------------------------------------
echo "Hello World" > file.txt

9.Append a data in a file
----------------------------------------
> echo "Hello" > file.txt    # create msg.txt
> echo "world" >> file.txt   # Adds "World" without deleting "Hello"

10. Handling Errors
----------------------------------------
lets understand first file Discriptors
> 0=stdin= Input
> 1=stdout= Output
> 2=stderr= Error

 To Redirect stdrr we use 2>, 2>>, or some another format

 > ls /path/does/not/exist/ 2> error.txt
 when we execute this command it will print an error in the error.txt file

 11. Searching in a File(s)
 -------------------------------------------
 we can do using grep command
 'grep'- Global Regular Expression Printer
 - it searches for text patterns inside file or coommnad Outputs and prints the matching lines

 example:
 grep "error" logfile.txt  # it will search for error in that file
 
 [a] case sensetive Vs case in-sensetive case
 ---------------------------------------------
 grep "hello" file.txt
 grep -i "hello" notes.txt   # -i it is case insensitive

 [b] Search in a Multiple files
 -------------------------------------
 grep "404" access.log error.log

 example:1
 create two file and add some error data
 > touch access.log
 > cat <<EOF > access.log
    there is a 404 error
    404 error in the program
    the is 404 error
    EOF
> touch error.log
 > cat <<EOF > error.log
    there is a 404 error
    404 error in the program
    the is 404 error
    EOF
> ls
> grep "404" access.log error.log

[c] Search in All files
---------------------------------
grep "error" *.txt
grep "404" *.log

[d] show number line with match
---------------------------------
grep -n "404" access.log
grep -n "404" error.log
grep -n "404" *.log

[e] Show only the matching part (not the whole line)
---------------------------------------------------------
grep -o cat error.log
grep -o cat access.log
grep -o cat *.log
