# What is Palindrome Number ?
- A number that reads Same Forward and Backword
Example:
```
121
1221
3223
4554
12321
```
Not Palindrome:
```
123
12345
```
## Logic
```
Step:1 Reverse The Number
Step:2 Compare with Original Number
```

## Logical Thinking
- 1. Start with the given number.
- 2. Create a Variable to store the reverse number.
- 3. Extract last digit of the number using modulus(n % 10).
- 4. Add this digit to the reversed number.
- 5. Repeat the process until the Original number is reduced to 0.
- 6. Finally compare the reversed number to the original.

## Let's Understand using : 121
```
Step             Digit          Reverse
121 % 10           1                1
12 % 10            2                12
1 % 10             1                121
```
Compare
```
121 === 121 => Palindrome Number
```
