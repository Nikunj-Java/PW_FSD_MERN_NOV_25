# Theta Nontation(Θ)
- it describes the tight bound case (exact growth rate)
- it will ensures that its best and worst cases are roughly the same

Example: Print n Numbers
```
function printNumbers(n){
    for(let i = 0; i < n; i++){
        console.log(i);
    }
}

```
## Conclusion
```
this loop always runs n times
so,
Best Case: n
Worst Case: n
```
## Complexicity
```
Θ(n)
```
