1. Install TypeScript using VS Code
>   npm install -g typescript@latest
2. Check the Version
>   tsc -v
3. To Run typescript
>   tsc app.ts
4. To Run javascript
>   node app.js
5. To run TypeScript Directly without using tsc
>   npx tsx app.ts
6. TypeScript Environment Setup
> tsc --init   
or 
> npx tsc --init
[it will create tsConfig.json file]
this file will define how .ts will be converted to .js
