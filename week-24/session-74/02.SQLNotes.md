## 11. Filters in Database
- 1. WHERE
- Syntax:
```

```

```

```
- Filter By NAME:
```

```
- Filter By DATE_ADDED:
```

```
- Filter By PRICE:
```

```
- GREATER THAN
```

- LESS THAN
```
SELECT * FROM eproduct WHERE price < 50000;
```
- LIKE
```
SELECT * FROM eproduct WHERE name LIKE "%Laptop%";
```
- BETWEEN
```

- AND 
```

- OR

## Transaction
- IT IS MAINLY USED IN TRANSACTION
- lETS CREATE TABLES;
- 1. Accounts Table 
```
create table accounts(id int auto_increment primary key, name varchar(50), balance decimal(10,2));
```
- 2. INSERT RECORDS
```
insert into accounts (name,balance) values ('Nikunj Soni',1000.00),('Alex',1200.00),('Jhon Doe',500.00);
```
- 3. Start Transaction
```
START TRANSACTION
```
- 4. Update the Balanace
```
update accounts set balance=balance-200 where name="Nikunj Soni"; 
update accounts set balance=balance+1200 where name="Jhon Doe"; 
```
- 5. Commit the Changes
```
commit;
``` 
- 6. Create 'SAVE POINT' for rollback the transaction
```
START TRANSACTION;
SAVEPOINT sp1;
update accounts set balance=balance-200 where name="Nikunj Soni";
ROLLBACK TO sp1;
```

## Relationship In Tables
- lets create two tables 
    - Customer
    - Order
- Idea: one customer can have many orders; (One-to-Many Relationship)
- Customer Table
```
CREATE TABLE customers( customer_id INT PRIMARY KEY AUTO_INCREMENT, customer_name VARCHAR(100));
```
- Order Table (customer_id is a reference from customer tablew(Foreign key))
```
CREATE TABLE orders(
    order_id INT PRIMARY KEY AUTO_INCREMENT, 
    product_name VARCHAR(100), customer_id INT, 
    FOREIGN KEY(customer_id) 
    REFERENCES customers(customer_id) 
    ON DELETE CASCADE
    );
```
- LET'S INSERT SOME RECORD
```
INSERT INTO customers(customer_name)
VALUES
('Nikunj Soni'),
('Rahul Shah');
```
```
INSERT INTO orders(product_name, customer_id)
VALUES
('Laptop', 1),
('Mobile', 1),
('Tablet', 2);
```
- DELETE ONE RECORD FROM CUSTOMER TABLE
```
DELETE FROM customers WHERE customer_id=1;
```
- Now Check the Records in Tables
```
SELECT * FROM customers;
SELECT * FROM orders;
```
Note: You will note that if you delete one record from customer table, its related data or no of rows in order table will be deleted Automatically

## Common Aggregate Functions
----------------------------
| Function | Purpose       |
| -------- | ------------- |
| COUNT()  | Counts rows   |
| SUM()    | Adds values   |
| AVG()    | Finds average |
| MAX()    | Finds maximum |
| MIN()    | Finds minimum |
----------------------------
1. COUNT
```
SELECT COUNT(*) AS TOTALEMPLOYEES FROM Employee;
```
- OUTPUT:
-------------------
| TOTALEMPLOYEES |
|----------------|
|              5 |
-------------------

```
SELECT SUM(Salary) AS TotalSalary FROM Employee;
```
- OUTPUT:
---------------
| TotalSalary |
|-------------|
|      265000 |
---------------

3. AVG
```
SELECT AVG(Salary) AS AverageSalary FROM Employee;
```
- OUTPUT:
-----------------
| AverageSalary |
|---------------|
|    53000.0000 |
-----------------

4. MAX
```
SELECT MAX(Salary) AS HighestSalary FROM Employee;
```
- OUTPUT:
-----------------
| HighestSalary |
|---------------|
|         70000 |
-----------------

5. MIN
```
SELECT MIN(Salary) AS LowestSalary FROM Employee;
```
- OUTPUT
-----------------
| LowestSalary |
|--------------|
|        40000 |
-----------------

## GROUP BY Clause
- GROUP BY is used to: Group rows having the same values.
- Usually used with aggregate functions.
- lets Create a New Table
```
CREATE TABLE users (
    user_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    full_name VARCHAR(100),
    email VARCHAR(100) UNIQUE,
    age INT,
    city VARCHAR(50),
    salary DECIMAL(10,2),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```
----------------------------------------------------------
| Column     | Type          | Purpose                   |
| ---------- | ------------- | ------------------------- |
| user_id    | BIGINT        | Unique user ID            |
| full_name  | VARCHAR(100)  | User full name            |
| email      | VARCHAR(100)  | User email                |
| age        | INT           | User age                  |
| city       | VARCHAR(50)   | User city                 |
| salary     | DECIMAL(10,2) | User salary               |
| created_at | TIMESTAMP     | Auto stores creation time |
----------------------------------------------------------
- lets inser some values
```

- GROUP BY
