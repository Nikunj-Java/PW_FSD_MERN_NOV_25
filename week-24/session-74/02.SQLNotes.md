# SQL Queries for MYSQL DataBase

## What is SQL Query?
- it is Called as Structured Query Language
- it is used to Manipulate MYSQL Database
- using SQL Query We Can Perform CRUD operation
- using MySQL Workbench or MYSQL CLI You can Use This SQL Queries

## 1. Create New Database
```
create database pwskills;
```

## 2. Get The List of Available Databases
```
show databases;
```

## 3. Use The Databases
```
use pwskills;
```

## 4. Delete / Drop Database in MySQL
```
drop database pwskills
```

## 5. Create Table in Database
- suppose you need to create table with Below Requirements
- create table eproduct(id,name,price,date_added)
- so we need to give datatype for each items
```
    - id = bigint
    - name= varchar
    - price= decimal
    - date_added= timestamp default now()
```
- in each table ther must be one primary key
- so lets create primary key using 'id'
```
    - id = bigint primary key
```
- now lets create automatic ad assign using auto-increment
```
    - id = bigint primary key auto_increment
```
- so we have to give following syntax
```
    - id = bigint primary key auto_increment
    - name= varchar(100)
    - price= decimal(10,2)
    - date_added= timestamp default now()
```
## Finally
```
create table eproduct(id bigint primary key auto_increment,name varchar(100),price decimal(10,2),date_added timestamp default now())
```

## 11. Filters in Database
- 1. WHERE
- Syntax:
```
SELECT * FROM table_name WHERE column_name=value;

```
- Filter By ID:
```
SELECT * FROM eproduct WHERE id=3;

```
- Filter By NAME:
```
SELECT * FROM eproduct WHERE name="Apple";
```
- Filter By DATE_ADDED:
```
SELECT * FROM eproduct WHERE date_added='2026-05-12 17:17:13';
```
- Filter By PRICE:
```
SELECT * FROM eproduct WHERE price="80000";
```
- GREATER THAN
```
SELECT * FROM eproduct WHERE price > 100000;
```
- LESS THAN
```
SELECT * FROM eproduct WHERE price < 50000;
```
- LIKE
```
SELECT * FROM eproduct WHERE name LIKE "%Laptop%";
```
- BETWEEN
```
SELECT * FROM eproduct WHERE price BETWEEN 60000 AND 120000;
```
- AND 
```
SELECT * FROM eproduct WHERE price > 50000 AND name LIKE "%Laptop%";
```
- OR
```
SELECT * FROM eproduct WHERE price > 100000 OR name="Oppo";
```
- ORDER BY
```
SELECT * FROM eproduct ORDER BY price DESC;
SELECT * FROM eproduct ORDER BY id DESC;
SELECT * FROM eproduct ORDER BY date DESC;
SELECT * FROM eproduct ORDER BY name DESC;
SELECT * FROM eproduct ORDER BY price ASC;
SELECT * FROM eproduct ORDER BY id ASC;
SELECT * FROM eproduct ORDER BY date ASC;
SELECT * FROM eproduct ORDER BY name ASC;
```
- LIMIT
```
SELECT * FROM eproduct ORDER BY name ASC LIMIT 3;
```
