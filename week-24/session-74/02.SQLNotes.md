# SQL Queries for MYSQL DataBase

## What is SQL Query?
- it is Called as Structured Query Language
- it is used to Manipulate MYSQL Database
- using SQL Query We Can Perform CRUD operation
- using MySQL Workbench or MYSQL CLI You can Use This SQL Queries

## 1. Create New Database
```
create database pwskills;
```

## 2. Get The List of Available Databases
```
show databases;
```

## 3. Use The Databases
```
use pwskills;
```

## 4. Delete / Drop Database in MySQL
```
drop database pwskills
```

## 5. Create Table in Database
- suppose you need to create table with Below Requirements
- create table eproduct(id,name,price,date_added)
- so we need to give datatype for each items
```
    - id = bigint
    - name= varchar
    - price= decimal
    - date_added= timestamp default now()
```
- in each table ther must be one primary key
- so lets create primary key using 'id'
```
    - id = bigint primary key
```
- now lets create automatic ad assign using auto-increment
```
    - id = bigint primary key auto_increment
```
- so we have to give following syntax
```
    - id = bigint primary key auto_increment
    - name= varchar(100)
    - price= decimal(10,2)
    - date_added= timestamp default now()
```
## Finally
```
create table eproduct(id bigint primary key auto_increment,name varchar(100),price decimal(10,2),date_added timestamp default now())
```
