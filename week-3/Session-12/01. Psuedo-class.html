Psuedo-class

Google.com

A pseudo-class is a keyword added to selectors that specifies a special state of the selected elements.

For example, it can be used to style an element when a user mouses over it, or to style visited links differently from unvisited links.

Summary

  • :hover- Works with Mouse Hover
  • :active- Works when the element is being activated(e.g., clicked)
  • :focus- Works when the element is focused(e.g., clicked or tabbed into)
  • :nth-child(n)- Selects the nth child of a parent element
  • :first-child- Selects the first child of a parent element
