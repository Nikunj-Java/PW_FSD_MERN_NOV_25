:: Represent Psuedo-Element

  1. ::before- Adds content before an element
  2. ::after- Adds content after an element
  3. ::first-letter- Styles the first letter of an element
  4. ::first-line- Styles the first line of an element
  5. ::marker- Styles the marker of list items
  6. ::placeholder- Styles the placeholder text of input fields
  7. ::selection- Styles the portion of an element that is selected by the user
